# Adeptia Migration — AJG

Azure DevOps CI/CD pipelines for Adeptia 4.x migration management.

## Folder Structure

```
├── pipelines/                  # Azure DevOps pipeline YAML files
│   ├── export-pipeline.yml
│   ├── import-pipeline.yml
│   ├── rollback-pipeline.yml
│   ├── promote-pipeline.yml
│   ├── promote-import-pipeline.yml
│   └── cleanup-pipeline.yml
├── artifacts/
│   ├── dev/                    # Export ZIPs from DEV environment
│   └── qa/                     # Export ZIPs from QA environment
├── rollback/
│   ├── executed/               # Marker files for executed rollbacks
│   └── *.zip                   # Rollback ZIPs (auto-generated on import)
├── migration-logs/             # Rollback migration logs
└── promote-config.txt          # Auto-generated by Promote pipeline (do not edit)
```

## Pipelines

| Pipeline | Trigger | Purpose |
|---|---|---|
| Export | Manual | Export ZIP from Adeptia, commit to repo |
| Import | Manual | Import ZIP into target environment |
| Rollback | Manual | Rollback a previous import |
| Promote | Manual | Export + create PR for multi-env import |
| Promote Import | Auto (PR merge) | Sequential import: QA → Stage → Production |
| Cleanup | Manual | Delete old ZIPs and stale branches |

## Required Variable Groups (Azure DevOps Library)

**adeptia-credentials**
- `ADEPTIA_EXPORT_USERNAME`
- `ADEPTIA_EXPORT_PASSWORD`
- `ADEPTIA_IMPORT_USERNAME`
- `ADEPTIA_IMPORT_PASSWORD`
- `AZURE_DEVOPS_TOKEN`

**adeptia-config**
- `EXPORT_APP_URL`
- `IMPORT_APP_URL`
- `IMPORT_PKG_ID`
